## 2026-06-04 - Fix XSS Vulnerability in Go Template Functions
**Vulnerability:** The `marshal` function in `internal/web/template_funcs.go` directly cast `json.Marshal` output to `template.JS`, bypassing the contextual escaping mechanisms of `html/template`. This allowed unsanitized inputs embedded within the JSON structure to be rendered maliciously within `<script>` tags, causing Cross-Site Scripting (XSS).
**Learning:** Functions that bypass context-aware template escaping (like `template.HTML`, `template.JS`, etc.) must be carefully reviewed. Relying on JSON marshaling to sanitize input is fundamentally flawed, as JSON's escaping rules are incompatible with HTML context within script tags.
**Prevention:** Remove custom wrapper functions that cast output to `template.JS`. Utilize Go's native `html/template` engine, which inherently and safely encodes structs/maps when rendering directly into `<script>` or `<script type="application/json">` tags, negating the need for manual JSON marshaling logic.
