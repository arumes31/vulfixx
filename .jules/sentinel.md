## 2026-07-09 - [Fix IP Spoofing vulnerability]
**Vulnerability:** The application was vulnerable to IP spoofing. The `middleware.RealIP` was used in `internal/web/router.go` before a custom `ProxyMiddleware`. `middleware.RealIP` blindly trusts `X-Forwarded-For` and `X-Real-IP` headers from any source. This allowed an attacker to bypass rate limiting or spoof their IP by injecting these headers, which `middleware.RealIP` would then use to overwrite `r.RemoteAddr`, rendering the custom `ProxyMiddleware` ineffective.
**Learning:** Security middlewares that rely on IP (like custom ProxyMiddleware or Rate Limiting) must ensure they are the authoritative source of the IP. Mixing standard middlewares like `middleware.RealIP` that trust headers blindly with custom middlewares that perform validation can lead to bypasses.
**Prevention:** Never use `middleware.RealIP` if the application is intended to perform custom trusted proxy validation. Only use custom middleware that verifies the source IP against a trusted list before accepting `X-Forwarded-For` or `X-Real-IP` headers.
