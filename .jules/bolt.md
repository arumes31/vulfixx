## 2024-06-10 - Merging fallback queries inside core loops
**Learning:** `internal/web/base.go`'s `RenderTemplate` method originally fetched user teams using one query, and then, if a specific team name wasn't found in that returned list, executed a *second* `QueryRow` fallback query. This led to unnecessary 1+1 queries during every single template render of the application.
**Action:** Always attempt to batch context-fetching queries. I used `LEFT JOIN` and an `OR` condition (`WHERE tm.user_id = $1 OR t.id = $2`) in a single query to simultaneously fetch both the list of user teams *and* the active team name in one database roundtrip.
