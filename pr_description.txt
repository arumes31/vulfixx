💡 What: Added `tabindex="0"`, an `aria-label`, visible focus states (`focus:bg-white/[0.05] focus:outline-none`), and `keydown` event listeners for the interactive CVE table rows on the dashboard.
🎯 Why: Table rows acting as navigation links previously could not receive focus and were not actionable via keyboard, completely blocking screen reader and keyboard-only users from interacting with them.
📸 Before/After: Visual focus state added (lighter background), keyboard navigation (Tab) now stops on rows, and pressing 'Enter' or 'Space' navigates to the CVE detail page.
♿ Accessibility: Ensures WCAG 2.1.1 (Keyboard) and 2.4.7 (Focus Visible) compliance for the primary data table.
